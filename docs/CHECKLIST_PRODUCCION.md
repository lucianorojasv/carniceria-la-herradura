# Checklist de producción

- [ ] Dirección y horario reales.
- [ ] Precios y stock reales.
- [ ] Fotografías propias o autorizadas.
- [ ] Zonas, tarifas y pedido mínimo.
- [ ] Métodos y números de pago.
- [ ] Contraseña de administrador cambiada.
- [ ] PostgreSQL con contraseña fuerte.
- [ ] JWT secreto aleatorio.
- [ ] HTTPS y dominio.
- [ ] CORS restringido.
- [ ] Backups diarios probados.
- [ ] Token de WhatsApp y webhook.
- [ ] Política de privacidad y consentimiento comercial.
- [ ] Prueba de pedido desde WhatsApp hasta entrega.
- [ ] Responsable humano para reclamos y excepciones.
